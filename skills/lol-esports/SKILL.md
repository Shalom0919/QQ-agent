这是本仓库的可执行 Skill，入口是 `skill.json` 和 `index.js`；无需安装到 Codex 的个人技能目录。

## 使用

放在 QQ Agent 的 `skills/lol-esports/`，在技能设置中启用「LOL 赛事记录」。新安装后重启机器人或重新扫描技能。无需私人 API Key，无新增 npm 依赖。

可直接对机器人说：

- 今天有哪些 LOL 比赛？不要剧透。
- 查询 2026-10-15 到 2026-10-22 的 Worlds 赛果。
- 查一下 T1 的选手阵容，Faker 在哪个队？
- 查刚才那场比赛的单局回放。
- 列出 LCK 的赛事届次，再查指定届次的排名。
- 用已有记录统计 T1 和 GEN 的交手胜负。
- 把这周已抓取的赛程导出为日历 / CSV。
- 查看赛事同步状态。

所有查询日期按北京时间解释。先用列表拿 ID，再查询详情；不要猜测赛事、届次或战队 ID。中文赛事别名支持世界赛、全球总决赛、季中赛、先锋赛；战队优先使用官方英文简称。

## 自动更新与记录

默认每15分钟抓取设置中的主要联赛，范围为最近7天至未来14天；机器人关闭期间不运行。历史查询会补充本地归档，同一赛事按官网 ID 更新。默认保留730天、最多30000场。数据写在当前机器人数据目录的 `lol-esports/archive.json`，遵循多账号数据目录隔离。

同一请求默认缓存5分钟，并合并并发请求。网络故障时，同一进程内已有缓存可作为过期数据返回；重启后仍可用 archive 查询落盘记录。状态工具报告最近完整同步时间和错误。分页上限默认5页，每页100场；超出会明确标注，缩小查询日期范围再查。

导出位于 `lol-esports/exports/`，支持 UTF-8 CSV、JSON、ICS。CSV 做公式转义；日历只含未开赛赛事，以赛事 ID 去重标识，3小时仅为估计时长，不是官方结束时间。日历是快照，不是自动订阅。导出不自动发文件或群发消息。

## 数据来源与边界

- 官方页面：https://lolesports.com/en-US
- 数据接口：https://lolesports.com/api/gql
- 使用官网公开网页自己的持久化只读查询；`operations.json` 保存2026-10-22实际验证的操作 ID。它不是 Riot 承诺稳定的开发者 API；网站升级后操作 ID 可能失效，需要从官网发布的 persisted query manifest 更新对应 ID，再运行联网冒烟测试。不要改接不明镜像或填入个人 Riot 密钥。
- 仅收录官网提供的赛事；不能保证所有地区的比赛、阵容、回放或历史记录完整。阵容是官网列示数据，可能含历史队员，不应断言为当场首发。
- 交手统计是本地样本统计，非官方积分榜。排名来自官网赛事阶段/分组数据，未提供就说明缺失。
- 不提供未经数据源验证的 KDA、BP、实时击杀、经济曲线或选手表现评分；赛果状态为未结束时不能当作最终结果。
- 尊重防剧透：不返回比分、胜者、单局状态和回放数量；不要另调排名或交手统计旁路泄露结果。
